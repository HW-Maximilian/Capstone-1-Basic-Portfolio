# HW-Maximilian-Capstone-1-Basic-Portfolio

## Portfolio Personale
Benvenuti nel mio portfolio! Questo repository contiene il mio sito web personale, realizzato utilizzando HTML e CSS. Al momento il sito è un lavoro in corso e viene costantemente aggiornato man mano che continuo ad imparare e a sviluppare nuove competenze nel web development.

### Cosa troverai
HTML e CSS: Il sito è costruito con una base solida di HTML5 e CSS3. Ogni pagina è progettata per essere semplice e chiara, con una struttura facilmente navigabile.
Design responsivo: Ho implementato un design che si adatta a dispositivi di diverse dimensioni (desktop, tablet, mobile) per garantire un'esperienza utente ottimale su ogni dispositivo.
Progetti in evoluzione: Questo portfolio è pensato per raccogliere e mostrare i miei progetti, iniziando dalle basi fino ad arrivare a lavori più complessi che svilupperò in futuro.
### Obiettivi futuri
Aggiungere più progetti e funzionalità man mano che acquisisco nuove competenze.
Migliorare l'aspetto visivo e l'esperienza utente.
Espandere le conoscenze includendo tecnologie come JavaScript, framework front-end (es. Bootstrap, React), e altro.
